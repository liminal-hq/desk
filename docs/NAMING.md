# Naming

"Desk" is the working name. It is what the repository (`liminal-hq/desk`), the launcher (`DESK.COM`), the core (`DESKCORE.EXE`), the SDK (`desk.h`, `desk_*`) and the settings file (`DESK.INI`) are called today. The product name is open, and choosing it does not block any work.

## Where the brainstorm started

The design-agent brainstorm called the project "Afterglow Desk". The Afterglow name is out of favour as part of the product's name: it overlaps with `liminal-hq/afterglow-themes` (the colour themes, which stay "Afterglow"), and the shell does not have to carry the brand's whole palette in its name. The Afterglow *look* (the void, the orange accent, the stepped halo) is unaffected and keeps its name inside the product.

## Candidates

| Candidate | For | Against |
|---|---|---|
| **Desk** (as is) | Short, plain, 4 letters, fits 8.3 (`DESK.COM`) | Generic: hard to search for, and others use the word |
| **Liminal Desk** | Fits the studio's name and the "in-between" idea (the place you come to after DOS boots) | Long on the launcher bar, `LIMDESK.COM` would be needed in 8.3 |
| **Desk 1.0** or another versioned sub-name | Reads like a period product (GEM, DESQview, Geoworks); can step to 1.1, 2.0 | Ties the brand to a version number; needs a rule for pre-release numbers |
| A new complete sub-name | Most distinctive | Needs inventing and checking |

## Constraints

- Executable and file names are 8.3, so the launcher and core names must fit regardless of the product name.
- The name appears in the hero banner (`assets/hero.svg`, regenerated by `tools/build-hero.py`), the README, `AGENTS.md`, `NOTICE`, the SPEC and the About boxes.
- Check for namesake products and trademarks before anything public carries the final name.

## When a name is chosen

1. Rename the GitHub repository with `gh repo rename` and move the local directory.
2. Update the hero banner text and regenerate it, then the README, `AGENTS.md`, `CLAUDE.md`, `NOTICE` and the SPEC's title.
3. Decide whether the 8.3 names (`DESK.COM`, `DESKCORE.EXE`, `DESK.INI`, `desk_*`) change. Keeping them is fine if they still read well; the product name and the file names do not have to match.
4. Record the decision here and remove the candidates that lost.
