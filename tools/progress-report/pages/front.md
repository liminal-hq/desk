Welcome to the stacks. I am Gregory, and I keep the archive of the Desk: a calm graphical operating system, written in Rust, for old hardware. The repository's first commit, at 10:37 on 22 October 2026, imported a design brainstorm for a DOS shell. The first of the {{m.prsMergeDay}} pull requests of merge day landed at {{pr3.time}} that night and the last at {{pr7.time}}. `main` is now at `{{head}}`, after the generator of this report (#9) was merged too: {{m.commitsAll}} commits, {{m.files}} files, a complete family of fonts, {{m.emojiPixel}} hand-drawn pixel emoji, a NASM boot sector that starts a Rust kernel in QEMU, and a Rust program that runs on DOS with no C beneath it. Besides the generator, {{m.prsOpen}} more pull requests have been opened ({{open.numbers}}) and none has been merged. Between them they hold a design for a shared hardware layer, drivers for it, a keyboard and mouse on both tracks, graphics from the bare-metal kernel and from DOS, a `std` experiment, a browser run, the same image in two more emulators, and a BIOS path for the native kernel. That is {{m.commitsBranches}} commits on branches, none of them on `main`, with CI green on the head of {{m.openCi}} of the pull requests.

**There is no operating system yet.** There are two skeletons, a stack of proven techniques, and, in the open pull requests, a first window with a cursor that the native kernel draws in an emulator. That window is a proof with its own code: the shared Desk core that is meant to draw windows on both tracks does not exist. Every run so far was in an emulator, and none on a real machine. The shelves below keep that straight: a thing is only *catalogued* when I can say how it was checked, it is *uncatalogued* when it is built and nobody has verified it, and it is on the *wish list* when it is only planned. Each item carries a small tag from `gh`: *merged*, *in review*, *in progress* or *planned*. Each chapter has its own shelves, its evidence and, where it helps, a small machine you can step through.

This archive is a work in progress: every pull request above is open, the tags on the pages say so, and each chapter says what it does not know.
