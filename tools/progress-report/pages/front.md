Welcome to the stacks. I am Gregory, and I keep the archive of the Desk: a calm graphical operating system, written in Rust, for old hardware. The repository's first commit, at 10:37 on 22 October 2026, imported a design brainstorm for a DOS shell. The first of the {{m.prs}} pull requests was merged at {{pr3.time}} that night and the last at {{pr7.time}}, so what you are looking at is the state of `main` at `{{head}}`: {{m.commitsAll}} commits, {{m.files}} files, a complete family of fonts, {{m.emojiPixel}} hand-drawn pixel emoji, a NASM boot sector that starts a Rust kernel in QEMU, and a Rust program that runs on DOS with no C beneath it.

**There is no operating system yet.** There are two skeletons and a stack of proven techniques, each run in an emulator and none on a real machine. The shelves below keep that straight: a thing is only *catalogued* when I can say how it was checked, it is *uncatalogued* when it is built and nobody has verified it, and it is on the *wish list* when it is only planned. Each chapter has its own shelves, its evidence and, where it helps, a small machine you can step through.
