Welcome to the stacks. I am Gregory, and I keep the archive of the Desk: a calm graphical operating system, written in Rust, for old hardware. The repository's first commit, at 10:37 on 22 October 2026, imported a design brainstorm for a DOS shell. The first of the {{m.prsMergeDay}} pull requests of merge day landed at {{pr3.time}} that night and the last at {{pr7.time}}. The next day brought the generator of this report, nine spikes, and then the first window, drawn by one shared core on both tracks with the same pixels. Then the work paused for nineteen days in review, and on 11 November a great deal landed at once. `main` is now at `{{head}}`: {{m.commitsAll}} commits and {{m.files}} files.

**What the last three weeks added.** The first window now answers a real mouse and keyboard on both tracks, in emulators (chapter 19). The owner ran it by hand for the first time and found four things that the checks could not see, one of which was fixed the same day (chapter 20). The original design of the whole shell has been captured and read against the code, and the roadmap now lists 140 items (chapter 21). CI went red on a package mirror and was moved to an image that carries its own tools (chapter 22). And a comparison with Lieutenant Fizz 2, which forked Desk's DOS runtime within days, has produced a decision to bring its improvements home (chapter 23). Beside the log there is also the Manual, a textbook of the layers, built from the same evidence.

**There is no operating system yet.** There are two skeletons, a stack of proven techniques, and a first window that a shared core draws identically on DOS (in DOSBox) and on the bare-metal kernel (in QEMU). It has two windows, a cursor, a text field and keyboard window switching; it has no launcher bar, no menus, no apps and no filesystem. Every run so far was in an emulator, and none on a real machine. The shelves below keep that straight: a thing is only *catalogued* when I can say how it was checked, it is *uncatalogued* when it is built and nobody has verified it, and it is on the *wish list* when it is only planned. Each item carries a small tag from `gh`: *merged*, *in review*, *in progress* or *planned*. Each chapter has its own shelves, its evidence and, where it helps, a small machine you can step through.

This archive is a work in progress, and each chapter says what it does not know.
